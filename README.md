### Key Features

1. **Interactive Role Lens Switcher**: Dynamically filters and re-ranks systems and credentials across `360° Architect Dossier`, `AI & Agentic Systems`, `Cloud & Security Architecture`, and `Data, KQL & Leadership`.
2. **Inline System Blueprint Inspector**: Expandable 4-stage architecture pipelines inside each flagship system card (*Use Case Intelligence*, *FutureGrid*, *University Signals*, *MCP & GitHub Copilot Workshops*, *Zero-Secret Workload Identity & Flux2 GitOps*, *Coding Agent Internals*).
3. **123-Credential Verification Matrix**:
   - **Domain DNA Bars & Yearly Velocity Chart (2019–2026)**
   - **Interactive Skill Tag Cloud & Instant Search**
   - **Inline Credential Dossier Drawer** with direct `Verify Official Credential ↗` links for every badge (zero modal popups).
4. **Bilingual (`EN` / `中文`) & Theme (`Light` / `Dark`) Support** + **Print / PDF Executive CV Stylesheet**.
